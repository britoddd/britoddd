## What I've built
###  🗨️ **[Indonesian Swear Words Detector](https://github.com/britoddd/indonesian-swear-words-detector)**
- Four-level Indonesian abusive-language classifier. Compared deep learning fine-tuned IndoBERTweet against machine learning model such as Naive Bayes, Logistic Regression and LinearSVC baselines.
- Built preprocessing pipeline to survive obfuscation: spaced-out characters, leet substitution, slang normalisation, Sastrawi stemming. [Try it here](https://huggingface.co/spaces/britod/swear-words-detector)  
`NLP` `Machine Learning` `Deep Learning`

 
### 🏡 **[Onoma Trace](https://github.com/britoddd/onoma-trace)**
- Predicts country of origin from a personal name across 104 countries, using character n-gram TF-IDF and linear models. [Try it here](https://huggingface.co/spaces)
`Machine Learning`
